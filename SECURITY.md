# Security Policy

The full security model — trust boundaries, the STRIDE threat model, the permanent
safety test suite, coverage thresholds for safety-critical packages, and input/identity/
supply-chain/secrets hardening — lives at [`docs/SECURITY.md`](docs/SECURITY.md). This
file exists only so GitHub's own Security tab (which looks for a security policy at the
repository root) finds it; `docs/SECURITY.md` is the canonical, authoritative document
and the one `INFINITEAI_BUILD_MANUAL.md` itself directs security work to update.

## Reporting a vulnerability

Do not open a public issue for a security finding. Report it to the repository owner
directly. See [`docs/SECURITY.md` §10](docs/SECURITY.md#10-reporting-a-vulnerability)
for the current, up-to-date reporting instructions.
