AWS Services & Per-School Workload

Multi-tenant SaaS on AWS — one shared cluster, one RDS instance, one Redis cluster. The cost model splits into a shared infrastructure baseline (fixed regardless of school count) and a per-school marginal cost driven by storage growth and LLM API usage. Figures below are for a production deployment in af-south-1 (Cape Town). All cost estimates are in ZAR at R18.50 = $1 USD (assumed rate for planning — verify against the SARB daily rate before budgeting). AWS publishes unit prices in USD; those are kept as-is in the service tables for reference.

School profile assumed: South African primary school, Grade R–7, serving 200–800 learners. Active usage 07:00–17:00 SAST, Mon–Fri, ~196 school days/year (4 terms, 39–40 teaching weeks). Nine user roles: teacher, HoD, SMT, SBST, admin, guardian, learner, platform_support, platform_admin.
