# Policy and legislation sources — provenance record

This file records provenance for every policy and legislation document supplied to the
ingestion pipeline. The same rule that applies to CAPS documents applies here: **derived
structure only is stored in the repository** — no source text, no PDF. The chain from a
system output back to a ratified clause starts here.

All documents were supplied by the project owner on or before 2026-08-13.
The authoring environment has no direct route to the public internet, so documents were
transferred directly rather than fetched automatically.

## Ingestion notes

All documents were transferred directly by the project owner. The authoring environment
has no route to the public internet. Where a publication date could not be confirmed from
the document itself, the version field is set to `'undated'` rather than estimating —
inventing a date would break the provenance chain that `explain()` depends on.

Two documents are recorded as `DRAFT` status in `SOURCE_DOCUMENTS.md` because their
publication dates could not be confirmed (`doe-public-school-policy-guide` and
`sace-pd-points-schedule`). Their derived structure is usable but should not be promoted
to `ratifiedBy` until a dated edition is located and re-ingested.
