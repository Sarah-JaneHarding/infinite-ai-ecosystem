What “built” actually means

Contracts, Prisma + RLS, Keycloak/Auth.js wiring in code, Brain L0–L4 APIs, DAG orchestrator, HITL approval queue, guardrail engine, eval harness, 55 agents, provisioning wizard, billing/dunning state machines, design system, role shells, runbooks, k6 scripts, Terraform written.

What “not ready” actually means

Teacher / HoD / SMT / SBST / Guardian / Learner surfaces render SAMPLE_ / MOCK_ / DEMO_ data. No tRPC client was found wiring those UIs to live pipelines. Five ROLE_NAV destinations 404. Three feature flags default off. Terraform never applied. Keycloak image blocked in the authoring sandbox.

What first release is not

Not national scale. Not Grades 10–12. Not all eleven official languages. Not Commons sharing. Not dunning emails. Not Phase-4 Kahoot/Plickers/Kami parity (OQ-008–013). First release = one (ideally three) schools, nine roles, live data on the happy paths, HITL gates real, POPIA consents real, safeguarding pager real.

SECTION 05

First-release scope — initial testing by role

A first release for user testing is not GA. It is the smallest slice where each invited role can complete one honest job on live (or school-ratified) data, under the eleven rules, without mock fixtures pretending to be a school.

IN SCOPE (MUST WORK)

  • SSO sign-in for all nine roles against Keycloak in the test environment.
  • One tenant, one campus, Grades in the school’s real phase band (R–7 if that is the school).
  • Teacher: generate a lesson draft, edit, submit for HoD approval.
  • HoD: approve or send back; coverage view of planned vs ATP (even if CE-09 is partial).
  • Admin: invite staff, confirm classes, ratify retention starting schedule.
  • SBST: open a case from a screening result, record a decision, export a pack (even if Monitoring branch is feature-flagged off).
  • SMT: see de-identified tier counts and a PD gap list with cohort suppression.
  • Guardian: see own child, grant/revoke a purpose-limited consent.
  • Learner: optional. If included, own space only, age-gated.
  • Platform support: inspect a run without seeing learner identifiers.
  • Platform admin: list the tenant, see metering, cannot open a child record.
  • Safeguarding refusal pages a named human or the pipeline does not go live.

OUT OF SCOPE (MUST NOT BLOCK)

  • All 55 agents on the happy path. First test: CE-05, one TB agent, AC-01/02, DW ingest, PD-04/05, HITL.
  • Commons / LE promotion to other tenants.
  • Dunning emails, SUSPENDED→CLOSED automation.
  • SA-SAMS bidirectional sync (CSV/manual load is enough).
  • WhatsApp, LTI, OneRoster, live quizzes, card-scan, Kami-style annotation.
  • Grades 10–12, unsupplied languages, IP-MULTI stubs.
  • LLM-judge used for promotion decisions (OQ-016) — use schema/eval gates only.
  • 3× peak k6 as a tester-week gate — run it, but a failed spike does not stop five teachers clicking if SLOs are observed.
  • Architecture walkthrough recording (OQ-020) — ops hygiene, not a role test.

RECOMMENDED TEST COHORT (FROM PILOT_PROTOCOL)

If you can only have one schoolDo this
Small primary, Starter, < 150 learnersValidates wizard, Starter economics, teacher+HoD+admin first. Add SBST/guardian in week 2.
Ideal: three schools as protocolSmall primary · large primary · school group. Do not wait for all three to start internal role testing on a sandbox tenant.

Week-4 protocol targets that apply to first release: wizard completed, readiness 100, ≥80% invite accept in 5 days, zero POPIA incidents. Week-8/16 metrics are after first release, not before it.

Exit criteria — when first release may start

All of the following must be true. This is stricter than “stages 00–18 complete” and weaker than GA.

GO — START ROLE TESTING

  • Environment up; Keycloak issues sessions for all nine roles.
  • Gateway credentials live; one traced CE-05 run succeeded.
  • Safeguarding pager reached a named human in a drill.
  • Invite email arrived for a staff user.
  • A named tenant exists (pilot school or explicit sandbox).
  • Retention ratified by a human for that tenant.
  • No ROLE_NAV link 404s for invited roles.
  • Teacher / HoD / Admin happy paths use live data, not SAMPLE_ fixtures.
  • HITL approve resumes the worker.
  • Monitoring pipeline is off or OQ-027 is closed.
  • Platform admin cannot open a learner record.
  • On-call named; incident process printed.

NO-GO — DO NOT INVITE TESTERS

  • Any role UI still rendering SAMPLE_ / MOCK_ / DEMO_ as if it were the school.
  • Safeguarding path throws GuardrailEscalationError in production.
  • Learner PII observed in a prompt, log, or Langfuse trace.
  • HITL bypass, skipped tests, or any to go green.
  • Invented CAPS hours, SIAS steps, or SACE points.
  • Commons sharing or dunning emails enabled “just to see”.
  • No human has ratified retention and CAPS sources are presented as school policy.
