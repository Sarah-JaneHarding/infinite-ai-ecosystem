# Teacher Toolbox: catalogue of whiteboard tools to replicate

Compiled 5 November 2026 from the tool lists of Classroomscreen, Gynzy, ClassTools, FreeClassroomTools, ClassDojo, Promethean ActivInspire and SMART Lumio, plus the Pink Cat Studio PDF. Where a vendor page gave only a tool name, the description is mine, not theirs.

**Rules every replica follows:** original code and artwork (no vendor code or art), one self-contained HTML file, no network calls, learner codes only (a label shown on the board never leaves the page), a named teacher decides before anything is passed on, nothing stored.

Priority key: **BUILT** done in this batch · **P1** next batch · **P2** later · **P3** only if asked · **NO** do not replicate, reason given.

Totals: BUILT 12, P1 17, P2 18, P3 10, NO 7 (of 64 tools).
