## Notes

- HTML artefacts carry the INFINITE-AI brand palette (rainbow stripe, Playfair Display / DM Sans / Space Mono, dark top-bar) — match this visual identity in all rendered outputs.
- PPTX templates are for MOD-04 document-generation flows; they inform the slide structure and field layout expected by the rendering pipeline.
- These files are reference quality only. They must not be used as production data or seeded into the Brain without HOD verification.
